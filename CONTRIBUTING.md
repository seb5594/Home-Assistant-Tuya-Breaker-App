# Contributing to standalone Tuya Breaker

This checkout contains one app, `tuya_breaker/`, with an independent version in `project.json`. The config, Dockerfile, translations and copied sources are generated by `tools/sync_project.py` and checked in CI.

The reviewed main-app base lives in `vendor/untuyaos3/` with an upstream commit and SHA-256 manifest. The general radio SDK lives in `vendor/wifi_helper/` and is separately pinned to the WiFi Namespace Helper repository. Update snapshots from exact reviewed commits, preserve their licenses and refresh checksums; never download floating code on startup or require sibling checkouts.

Own Breaker modules, controllers and scripts live in `tuya_breaker/app/`; UI structure/extensions in `tuya_breaker/ui/`. Edit base UI/runner modules in the upstream UnTuyaOS3 repository, then intentionally refresh this snapshot. API protocol compatibility is independent of release numbers.

Use Python 3.11+ with PyYAML, run the generator check and full `tests/` suite, and run `node tests/test_webui.cjs`. Optional `tools/check_breaker_ui.cjs` uses Playwright with canned APIs at 360, 390 and 1280 pixels; it never contacts a real device. Build the one app context and run `.github/tests/runtime.sh` inside its image. AppArmor, exact upstream patches and both Python 3.13 environments are verified in CI.

The `dev` default branch publishes through hass-workflows after checks and both architecture builds. `.github/images.json` assigns a fresh registry package while preserving installed slug `tuya_breaker`. No host networking, host D-Bus, SYS_ADMIN or host API may be added. Verify cancellation, worker process groups, adapter return and failed cleanup. Describe physical-device validation separately; Lightleak remains experimental and changes target flash.
